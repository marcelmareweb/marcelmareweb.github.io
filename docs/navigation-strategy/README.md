## Investigation scope

Completed 30 October 2026 against local baseline commit 1a39ca9d28ff14331dbd0cdbbeb7d8b9de970562.

Eight local destinations were inspected at desktop and mobile widths, with actual menu, exercise, card, programme, course and enquiry-context interactions. Additional checks covered keyboard selection, short landscape, reduced motion, native fallbacks without JavaScript, local links and linked public resources.

Twenty-two local URL/anchor combinations passed the reachability/target checks. Twelve public linked destinations responded 200 at the audit time. Synthetic enquiry success/failure tests intercepted all POST requests; no live message delivery was tested or performed.

Findings distinguish rendered observations, source confirmation, inferred needs and proposals. Customer behaviour and conversion improvement remain to be tested.
